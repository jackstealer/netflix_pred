## 🆘 Need Help?

### Git Issues
- **Not installed**: Download from https://git-scm.com/downloads
- **Authentication**: Use Personal Access Token or SSH keys
- **Conflicts**: See SETUP_GITHUB.md

### Application Issues
- **Won't run**: Check Python version (need 3.11+)
- **Import errors**: Run `pip install -r requirements.txt`
- **Data issues**: Try different date range or CSV file

### GitHub Issues
- **Can't push**: Check authentication
- **Large files**: Already excluded in .gitignore
- **Workflow fails**: Check .github/workflows/streamlit-app.yml
